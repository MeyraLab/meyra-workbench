# 富爸爸资产框架

把清崎跨书的**教学结构**做成界面，而不是摘录原文。核心判断只有一句：

> 资产把钱放进口袋；负债把钱拿出口袋。

## 何时用

- 个人工作台、家庭账本、教练看板需要「资产框架」而不是银行对账
- 用户要看见 **现金流方向**，而不只是净值快照
- 需要把职业路径画成 **E / S / B / I** 象限（当前 vs 目标）
- 需要轻量 **财商四技能**（会计 / 投资 / 市场 / 法律）自评，而不是答题引擎

不要用它做：真实券商接入、收益率承诺、投资建议文案。界面必须有一句免责声明。

## 四层结构（按这个搭 UI）

1. **定义层（Rich Dad Poor Dad）**  
   每张卡片只回答：它每月是 `+` 还是 `−`？名字、类型、月现金流、一句备注。房子、车子、订阅如果在掏钱，放进负债栏。

2. **报表层**  
   并排两张纸：  
   - 损益表：流入 / 流出 / 月净现金流  
   - 资产负债表：资产件数 / 负债件数  
   工作收入可以当种子，但主视觉应落在**资产栏是否在付钱**。

3. **象限层（Cashflow Quadrant）**  
   `E 雇员` `S 自雇` `B 企业主` `I 投资人`。  
   左边用时间换钱，右边用系统与资产换钱。UI 要同时标 **当前** 与 **目标**，避免只有一个状态。

4. **素养层（Investing / financial IQ）**  
   四根柱子用 1–5 滑杆即可：会计、投资、市场、法律。缺一柱就提示棋盘会倾斜，不要做成测评分数。

## 设计原则

- **中文为主**，Asset / Liability / ESBI 作次要芯片。
- **棋盘隐喻**：地契色带卡片、毡面、奶油纸、金边、机会卡。灵感来自经典桌游，但必须是**原创布局与命名**（机会卡 / 财商卡），不要复制 Monopoly 商标、角色、或标准街区色序。
- **动效克制**：卡片发牌、现金流数字跳动、当前象限棋子。尊重 `prefers-reduced-motion`。
- **本地优先**：v1 用 localStorage；示例条目必须标「示例」，可清空。
- **教练口吻**：短提示问「它给我钱还是向我要钱？」；禁止长篇书摘。

## 组件清单（最小可用）

| 模块 | 必有字段 | 交互 |
| --- | --- | --- |
| 资产卡 | 名称、类型、月 `+`、备注 | 增删改 |
| 负债卡 | 名称、类型、月 `−`、备注 | 增删改 |
| 现金流井 | 流入 / 流出 / 净值 | 随卡片即时重算 |
| ESBI | current + target | 点选 + 星标目标 |
| 财商卡 | 短提示 | 抽一张循环 |
| 四技能 | 1–5 | 滑杆，写入同一份存档 |

类型色带保持原创：房产、企业、纸面资产、商品、知识产权；负债用另一组深色带，避免「同一套街区颜色」。

## 文案边界

可用：教学摘要、自己的短教练句、象限缩写。  
不可用：大段书中故事、商标口号、假称「官方现金流游戏」。  
页脚固定：「个人学习框架，非投资建议。」

## 落地检查

- 空状态仍能添加第一张资产
- 示例可识别、可清除，清除后不再自动灌回
- 刷新后 localStorage 仍在
- 深浅色都读得清毡面与奶油纸对比
- 不把负债画成「失败」，只标出现金方向
