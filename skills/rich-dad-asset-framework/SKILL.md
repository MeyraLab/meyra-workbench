# 富爸爸资产框架

把清崎跨书的**教学结构**做成界面，而不是摘录原文。核心判断只有一句：

> 资产把钱放进口袋；负债把钱拿出口袋。

宿主如果已有设计系统（如 Meyra OS），跟它的标题、色票、列表、reveal 走。不要另起一套桌游皮肤。

## 何时用

- 个人工作台需要「每周一眼」而不是银行对账
- 用户卖 Prompt Kit / 模板等 **数字产品资产**（B 象限），这比投资组合 UI 更重要
- 要同时标 ESBI **当前** 与 **目标**
- 需要把损益表字段和资产负债表条目分开，但都影响月现金流

不要用它做：券商接入、收益率承诺、投资建议。页脚固定：「个人学习框架，非投资建议。」

不要复制 GPL 或其他现金流游戏/软件的代码与版式；只复用公开教学结构。

## 数据模型（报表，不是游戏棋盘）

对照常见财务报表，而不是桌游格子：

**损益表（每周看的三格）**

| 字段 | 含义 | 来源 |
| --- | --- | --- |
| 主动收入 | 用时间换钱（E / S：工资、接案） | 手填 |
| 被动 / 半被动 | 资产与数字产品把钱放进口袋 | **加总**，不手填 |
| 固定支出 | 生活与运营的固定流出 | 手填 |

**资产负债表（影响现金流的条目）**

| 字段 | 含义 | 月现金流 |
| --- | --- | --- |
| 资产 | 授权、租金等仍在付钱的东西 | `+` |
| 负债 | 贷款、订阅等仍在要钱的东西 | `−` |
| 数字产品资产 | 上架数、月销售、更新成本 | 销售 − 更新成本 |

**月净现金流**

`主动收入 + Σ资产月流入 + Σ(数字产品销售 − 更新成本) − 固定支出 − Σ|负债月流出|`

被动格 = 资产月流入 + 数字产品净额。不要再做一个可填的「被动」以免重复计算。

数字产品单独成块：卖家的 B 面是 listing 与维护成本，不是股票行情。

## 象限

`E 雇员` `S 自雇` `B 企业主` `I 投资人`。左边用时间，右边用系统。当前与目标各一排芯片即可，不必做聚光灯棋子。

## 设计原则

- **中文为主**，Active / Passive / ESBI 作次要标签
- **跟宿主 OS**：`os-world-title`、HUD 芯片、log 行、card 阴影、light/dark token
- 允许极轻的「卡片」暗示（一行强调色、类型标签），不要毡面、骰子、钞票堆
- 动效只用已有 reveal；尊重 `prefers-reduced-motion`
- localStorage；示例标「示例」，清空后不要自动灌回

## 文案边界

可用：教学摘要、短教练句、象限缩写。  
不可用：书中故事、商标口号、假称官方现金流游戏。
